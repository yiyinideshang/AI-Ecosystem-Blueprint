# 06 · 局限性与风险分析

> 每一层都有它的"阿喀琉斯之踵"。认知风险，才能在选型和使用时不踩坑。

---

## 一、分层风险地图

| 层级 | 核心风险 | 风险描述 |
| :--- | :--- | :--- |
| **L1 模型** | 智能天花板 | 幻觉、知识截止、推理出错；能力上限即整个链路上限 |
| **L2-A 传统应用** | 同质化 | 调同一批模型，体验趋同，拼不过就只能拼价格与流量 |
| **L2-B 智能体** | 自主性反噬 | 执行错误、越权操作、工具滥用；权限越大，事故越大 |
| **L3 网关** | 单点依赖 | 网关宕机 = 全链路瘫痪；还存在中间人 / 数据留存风险 |

---

## 二、L1 模型层风险详解

- **幻觉（Hallucination）**：模型会"一本正经地胡说八道"，在事实性任务中尤其危险。
- **知识截止**：训练数据有截止日期，无法覆盖最新事件，需依赖联网 / RAG 补充。
- **算力与成本**：大模型推理成本高，长上下文、多模态会进一步推高 Token 消耗。
- **数据隐私**：调用第三方 API 意味着数据出域，涉密场景需私有化部署。
- **能力天花板**：下游 L2 / L3 再强，也无法突破 L1 模型本身的智能上限。

---

## 三、L2 应用层风险详解

### L2-A 风险
- **同质化竞争**：底层都是几家主流模型，应用层差异化难，易陷入价格战。
- **强依赖上游**：模型涨价 / 限流 / 停服，应用直接受冲击。

### L2-B 智能体特有风险
- **执行错误**：自主规划可能走偏，错误被执行放大（改错文件、跑错命令）。
- **安全边界模糊**：拥有文件系统 / 命令行权限，越权操作风险高，需严格的权限沙箱与审批。
- **工具滥用**：为完成任务可能调用不该调用的工具，或产生意料之外的副作用。
- **成本不可控**：自主多步执行会消耗大量 Token，账单可能远超预期。

> 🛡️ **缓解建议**：本地终端型智能体务必做到"最小权限 + 人工确认关键操作 + 用量上限告警"。

---

## 四、L3 网关层风险详解

- **单点故障**：所有流量经过网关，网关宕机则全员断服，需多活 / 容灾。
- **中间人风险**：网关可读取全部请求 / 响应，存在数据留存与泄露隐患，需评估其合规与信任度。
- **成本黑盒**：加价转售模式下，真实上游成本不透明，用户难以判断定价是否合理。
- **稳定性传递**：上游模型抖动会经网关放大，需配合故障转移与限流降级。

---

## 五、选型自查清单

选一个 AI 产品前，先问自己：

- [ ] 它属于哪一层？能力上限由谁决定？
- [ ] 我的数据是否敏感？能否接受出域？
- [ ] 它是单点还是多模型可切换？故障时有无兜底？
- [ ] 成本是按量、订阅还是加价？有没有用量上限保护？
- [ ] 如果是 L2-B，它的权限边界和审批机制是否清晰？
